==============================================================================
OVERVIEW                                                   *deja-view-overview*

Deja View restores your cursor and viewport when you reopen a file. Neovim
can kind of do this already (see |last-position-jump|), but it only restores
the cursor, not the scroll position. This plugin remembers the whole view
using |winsaveview()|.

The plugin is active as soon as it's installed. No configuration required.

==============================================================================
SETUP                                                         *deja-view.setup*

Configuration is optional. If the defaults don't suit you, pass overrides to
the `setup` function:
>lua
  require('deja-view').setup({
    -- Where views are saved. This is the default:
    save_dir = vim.fs.joinpath(vim.fn.stdpath('state'), 'deja-view'),
  })

Views are stored as JSON, one file per remembered buffer. File names are
escaped and written flat, much like 'undodir'.

==============================================================================
DRIVERS                                                     *deja-view-drivers*

A driver decides where a buffer's view is stored. Three are built in:

- `deja-view.disk`: persist views across sessions.
- `deja-view.memory`: remember views for the current session only. Useful for
  virtual buffers, like help pages, man pages, or file browsers.

By default, real files are saved to disk while commit messages and terminal
buffers are skipped; the same path holds different content every time, so
restoring a view would do more harm than good.

                                                        *deja-view-config.driver*
To change this, pass a `driver` function to `setup`. It receives the buffer
number and returns a driver, or `nil` to never remember the buffer:
>lua
  require('deja-view').setup({
    driver = function(bufnr)
      -- Keep help pages in memory instead of persisting them.
      if vim.bo[bufnr].buftype == 'help' then
        return require('deja-view.memory')
      end

      -- Fall back to the built-in behavior.
      return require('deja-view.driver').default(bufnr)
    end,
  })

==============================================================================
API                                                             *deja-view-api*

>lua
  local deja_view = require('deja-view')

  -- Optional. Overrides the default config.
  deja_view.setup({ ... })

  -- Save the current window's view. Runs automatically on |BufLeave| and
  -- |VimLeavePre|.
  deja_view.save()

  -- Restore the current window's view. Runs automatically on |BufReadPost|.
  -- Ignores views that look stale or out of bounds.
  deja_view.restore()
